## Overview

QuakeSpasm is the most trusted Quake 1 source port, based on FitzQuake and actively maintained for modern Windows, Linux, and macOS. It provides 64-bit builds, OGG Vorbis and MP3 soundtrack replacement, extended engine limits for large community maps, and improved OpenGL rendering — all while maintaining 100% compatibility with the original Quake 1 content, episodes, and the full mod ecosystem spanning three decades of community creation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **QuakeSpasm** delivers the features you need in a clean, intuitive package.

> Official website: [quakespasm.sourceforge.net](https://quakespasm.sourceforge.net)

## Key Features

| Feature | Description |
|---------|-------------|
| **64-Bit Builds** | Native 64-bit executables for Windows, macOS, and Linux systems |
| **OGG/MP3 Music** | Replacement music tracks via OGG Vorbis and MP3 file support |
| **Extended Limits** | Raised entity, model, and BSP limits enabling large community maps |
| **Full Mod Compat** | 100% compatibility with original Quake mods, add-ons, and total conversions |
